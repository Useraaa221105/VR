# 🍲 Подземелье вкусностей

**VR-игра: симулятор повара и охотника на монстров** для Meta Quest 3.
Учебный проект по дисциплине «Разработка приложений для виртуальной реальности».

> Проект вдохновлён мангой и аниме *Dungeon Meshi* («Подземелье вкусностей»).

## О проекте

Днём игрок управляет таверной и кормит гостей супами, ночью спускается в подземелье и **сам добывает ингредиенты**, то есть монстров. Монстров не убивают ради очков, их «добывают» для супа: у каждого свой инструмент и своя техника.

Главная идея: важно не просто попасть, а **как** выполнено движение. Удар засчитывается по реальным параметрам руки:

- скорость кончика инструмента (усреднение за 0,1 с);
- угол (плашмя или ребром, сверху или сбоку);
- зона попадания (голова, шея, спина, панцирь, чешуя);
- момент удара (окно уязвимости монстра).

Ошибка на охоте видна на кухне (нет ингредиента, нет супа), а ошибка на кухне видна в доходе таверны.

## Игровой цикл

```
Охота в подземелье → Готовка → Подача гостям → Монеты → Новые инструменты и этажи
```

| Этап | Что открывается | Этаж |
|------|-----------------|------|
| 1. «Первые гости» | Лопатка и сачок | −1 Верхние пещеры |
| 2. «Вечерний наплыв» | Тесак | −2 Заросшие руины |
| 3. «Пир для знати» | Молоток | −3 Затерянная крепость |
| Финал | Котёл-щит | Логово дракона |

## Особенности

- 🗡️ **6 монстров и босс**: слайм, ходячий гриб, мандрагора, василиск, живые доспехи, мимик, красный дракон.
- 🍜 **7 рецептов**: от желейной похлёбки до драконьего супа.
- 🧭 **Процедурная генерация этажей** (6–9 комнат, детерминированная по seed, менее 2 секунд).
- ✋ **Всё руками**: почти нет кнопок, инструменты висят на теле игрока.
- 🎓 **Обучение без инструкций**: карточки бестиария с демонстрацией «так / нельзя», подсказки по приоритету, напарник-официант Тоби.
- 😌 **Комфорт в VR**: нет тряски камеры, переходы телепортом под затемнением, поворот рывком, режим «сидя», режим для левши.

## Технологии

| Компонент | Что используется |
|-----------|------------------|
| Движок | Unity 6 (URP) |
| Взаимодействие в VR | XR Interaction Toolkit 3, OpenXR |
| Навигация монстров и гостей | NavMesh |
| Тесты | Unity Test Framework |
| Данные и баланс | ScriptableObject-конфиги |
| Сохранения | JSON |
| Платформа | Meta Quest 3 |

## Архитектура

- Одна постоянная сцена `Core` (XR Origin, сервисы) и подгружаемые additive-сцены: `Tavern`, `DungeonFloor`, `DragonLair`, `Lab_Arena`.
- Сервисы: реестр сервисов, шина событий (`EventBus`), машина состояний игры, переходы, сохранения, подсказки, пулы объектов, звук.
- Модули общаются через события, а не напрямую.
- Логика, не зависящая от движка (рецепты, математика ударов, рюкзак), написана на чистом C# и покрыта юнит-тестами.
- Правила кода: файл не более 400 строк, ноль аллокаций в `Update`, отдельная сборка (`asmdef`) на модуль.

## Как запустить

1. Установите Unity Hub и Unity 6 с модулем Android Build Support (для сборки под Quest).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Useraaa221105/VR.git
   ```
3. Откройте папку проекта через Unity Hub.
4. Откройте сцену `Core` и запустите в редакторе (XR Device Simulator) либо соберите APK для Quest 3.
